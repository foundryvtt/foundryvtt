Pings are temporary visual cues that help draw the attention of other users to a specific location in the map. Gamemasters can also use pings to forcibly reposition their players' maps to focus on the chosen location.

To ping the map, you should first check if the Token Controls layer is active and switch to it if needed, because pinging is only possible inside it. Next, just move the mouse cursor to the desired location in the map, press the Left-Click mouse button, and hold it down for a second.

Basic Ping

The most basic ping creates a pulsing ripple under your cursor using your selected user color.

Basic Pings are created by pressing and holding Left-Click on the canvas.

Alert Ping

The alert ping creates a pulsing red triangle under your cursor.

Alert Pings are created by pressing and holding ALT + Left-Click on the map.

Pan Canvas Ping

Only a Gamemaster (or Assistant) can use this ping.

The Pan Canvas Ping (or "Drag" or "Pull" Ping) creates a circle on the map followed by a downward pointing arrow, both using your selected user color.

The purpose of this ping is to shift other people's perspective to match yours. All users on that scene have their views panned to center on the ping location and zoomed to match your zoom level.

Pan Canvas Pings are created by pressing and holding SHIFT + Left-Click on the map.

Alternate appearances

Distant pings

Any users on the scene with you will see the ping, and any users on the scene with you but not looking at the same part of the map will see a pulsing arrow along the edge of the UI indicating the direction of the ping.

Slower ping animation

If you have Photosensitivity Mode enabled in the @Article[settings], all pings will appear to use the slow circle-and-arrow "pull" animation (even if they are not pull pings).

API Reference

To interact with pings programmatically, use the following API concepts:

  • Canvas#ping (display a ping at a point)
  • ControlsLayer#handleping (handle a broadcast ping)
  • @API[classes/foundry.canvas.interaction.Ping, Ping] (base ping class)
  • @API[classes/foundry.canvas.interaction.PulsePing, PulsePing] (basic pulse ping) , @API[classes/foundry.canvas.interaction.AlertPing, AlertPing] (alert ping) , @API[classes/foundry.canvas.interaction.ChevronPing, ChevronPing] (pan canvas ping)
