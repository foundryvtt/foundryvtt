Updated November 3, 2026 (Version 14.370)

Pings are temporary visual guides used to point things out on the canvas, highlight, or alert other users. Gamemasters can also use pings to reposition player cameras to view specific parts of the canvas.

All pings are created by a long held Left-Click of the mouse on the game canvas while having any of the Token Controls tools selected.

Basic Ping

The most basic ping creates a pulsing ripple under your cursor using your selected user color.

Basic Pings are created by pressing and holding Left-Click on the canvas.

Alert Ping

The alert ping creates a pulsing red triangle under your cursor.

Alert Pings are created by pressing and holding Alt + Left-Click on the canvas.

Pan Canvas Ping

(Gamemaster Only)

The Pan Canvas Ping (or "Drag" or "Pull" Ping) creates a circle on the canvas followed by a downward pointing arrow, both using your selected user color.

The purpose of this ping is to shift other people's perspective to match yours. All users on that scene have their cameras panned to center on the ping location and zoomed to match your zoom level.

Pan Canvas Pings are created by pressing and holding Shift + Left-Click on the canvas.

Alternate appearances

Distant pings

Any users on the scene with you will see the ping, and any users on the scene with you but not looking at the same part of the canvas will see a pulsing arrow along the edge of the UI indicating the direction of the ping.

Slower ping animation

If you have Photosensitivity Mode enabled in the @Article[core-settings], all pings will appear to use the slow circle-and-arrow "pull" animation (even if they are not pull pings).

API Reference

To interact with pings programmatically, use the following API concepts:

  • Canvas#ping (display a ping at a point)
  • ControlsLayer#handleping (handle a broadcast ping)
  • @API[classes/foundry.canvas.interaction.Ping, Ping] (base ping class)
  • @API[classes/foundry.canvas.interaction.PulsePing, PulsePing] (basic pulse ping) , @API[classes/foundry.canvas.interaction.AlertPing, AlertPing] (alert ping) , @API[classes/foundry.canvas.interaction.ChevronPing, ChevronPing] (canvas pan ping)
